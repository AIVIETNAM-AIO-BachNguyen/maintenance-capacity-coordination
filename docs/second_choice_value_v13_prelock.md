Status: locked before any v13 diagnostic outcome, 2026-10-23 Asia/Taipei. ## Hypothesis, contract, estimand

Use the two already fixed v12 N5/K3 configurations `n5k3_residual_a/b` with unchanged request/physical simulator, threshold PM, automatic CM, H48+tail16 and original failure/restoration/cost law. Load **all three DEV-selected C12 checkpoints** per case from the audited corrected-source run `artifacts/same_tick_v12_train_20261023T015159675542Z`; preserve their checkpoint identities. No retraining or checkpoint selection. Future event tapes exist only inside the diagnostic simulator; the C12 policy continues to receive present-state observations only. Internal first/second choices remain provisional; only complete forced matching executes physically.

On each fresh raw physical seed, follow deterministic C12 for one episode. Select the **first** tick in the inclusive window 8..39 for which C12 chooses a legal first edge and at least two distinct legal second edges remain. Select at most one state per case/root/raw seed; keep nonqualifying episodes in counts. For every residual second edge, force the exact two-edge matching consisting of C12's first edge and that second edge at the selected tick. Thereafter follow the **same C12 checkpoint** greedily through H, then use the inherited risk tail. Compare remaining H+tail economic cost from the selected state onward; past cost is common and cancels. All candidate matchings have the same cardinality, so this test isolates which second assignment is made. It does not evaluate STOP, a third assignment, or a learned policy that chooses the best edge.

For each selected state, use eight **independent continuation event tapes** with common random numbers across candidate second edges. Bank A comprises slots 0..3 and bank B slots 4..7. Choose the best (lowest mean future cost) and worst (highest) second edge using bank A only, breaking ties by edge token. The primary state-level estimand is bank-B mean future cost of the A-worst edge minus bank-B mean cost of the A-best edge. Bank B is not used to select the pair. This validation gap can be negative; a positive gap estimates a ranking signal that survives independent future events. Aggregate selected-state gaps equally within each case and report training-root means. Bootstrap raw physical seed ID as one cluster across cases and roots (5,000 resamples, seed `75713000`). Also report bank-A spread, bank-B spread, selected-state coverage, cost components and compute. No per-state or local regret is summed and called episode gain.
