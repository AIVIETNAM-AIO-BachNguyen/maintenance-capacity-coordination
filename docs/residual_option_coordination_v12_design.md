# Candidate-conditioned residual-option coordination v12 — design and prelock

Status: locked before v12 scientific training, DEV or held-out outcomes, 2026-10-23 Asia/Taipei. This is the one current successor hypothesis after the audited v11 no-go. V1–v11 gates and results remain closed. Simulator trajectories supply RL data; real factory logs are optional calibration. No new TEST is authorized.

## Distinct question and causal contrast

Source inspection of v11 shows its within-tick context averages **all unselected** machine and worker embeddings. The average includes machines without an admitted pending request and technicians already busy. It also gives every currently legal candidate edge the same context vector, so the candidate-specific matching opportunities it would remove are only implicit in the local edge embedding. V11's audited C11–CF11 physical contrast was −0.12 H+tail and cannot establish useful feedback. Its post-pilot 636/9,216 C11-visited states with any multiple-second-edge option show more exposure than N4/K2 but do not prove economic headroom. These facts motivate a distinct representational question, not a revised v11 threshold or case selection.

For each provisional partial matching and legal candidate edge e, form the **residual feasible edge graph after e** using only current admitted requests, physical compatibility, currently idle technicians and provisional used-machine/worker masks. Aggregate the existing learned edge embeddings over this residual graph with mean, elementwise maximum and cardinality. The candidate's score uses its own edge embedding, this candidate-conditioned residual summary, and the embedding sum of already selected provisional edges. STOP uses the corresponding current feasible-graph summary. After choosing e, recompute these summaries for the new partial matching. Thus candidate scores can respond to which *other* options the candidate would block; this is a concrete within-tick opportunity-cost representation, without advancing the simulator or adding a forecast or reward term.

C12 recomputes the candidate-conditioned residual summaries after each chosen edge. D12 uses **the same modules, raw present-state observations, masks and initial candidate logits**, but freezes every candidate and STOP context tensor computed at the initial root. The legal edge mask still updates. Same-weight CF12 loads a selected C12 checkpoint into D12 only at evaluation. B12 uses direct features rather than shared machine/worker encoders while retaining the residual-option decoder, so C12–B12 tests learned representation rather than sequentiality. S12 structured complete-action and G12 flat full-information are scratch matching controls; Q12 flat always-request is a different-admission control. F1 risk matching and F2 six-tick rollout run on the same physical tapes. Frozen historical V14 is N4/K2-dimension locked and remains an external reference, never a same-panel N5/K3 control.

This is an implementation/test of candidate-conditioned residual options, not a claim that recursive matching, graph representations or resource reservation are new. AirME/HetGPO already has recursive assignment and skip/STOP, as documented in the v8 proposal. The hypothesis can fail if remaining candidate matchings have nearly identical downstream value, PPO does not learn the opportunity summary, or deterministic sequence decoding is a poor inference rule. The primary falsifier remains C12–D12 paired H+tail; C12–CF12 checks whether deployed within-tick recomputation itself helps with fixed weights. C12 beating only G12 or B12 is insufficient.

## Operating contract, cases and probabilities

Use the unchanged `RequestEnv` physical transition, threshold PM submission, automatic CM, non-preemptive service, inherited failure/restoration/cost law, H48+tail16 and legal partial matchings/WAIT. No request fees, forced shutdowns, hidden future-event input, reservation, early PM admission or physics edits. Use the **pre-existing** `family_config("n5_k3_sparse", seed, "full")` N5/K3 generator with new fixed configuration seeds `74740000` and `74740001`, named `n5k3_residual_a/b`, replacing only horizon with 64. These cases are fixed by this document before inspecting their matrices or outcomes; neither may be dropped. The physical catalogue has 136 complete partial matchings including WAIT. All same-admission arms see identical present-state information and physical matching/WAIT actions.

C12/D12/B12 use PPO over a masked **ordered internal sequence** of at most three edge tokens plus STOP/forced end. One physical H transition and reward follows the completed matching; an internal edge is only a provisional decoder choice. Exact conditional log probabilities sum for PPO's old/new ratio. Multiple sequences can produce the same physical matching; sequence probability and entropy are never called matching marginals or entropy. Deterministic evaluation is tokenwise greedy, not guaranteed to select the maximum-probability matching. Feasibility removes selected machines/technicians and allows STOP at any non-forced step. S12/G12/Q12 use a categorical over the complete legal matching catalogue.
