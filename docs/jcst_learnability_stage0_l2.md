## Source audit

`component_framework_v1.advance` adds fixed risk-tail cost to the reward on the final H step only. The L1 collector divides every controlled reward, including that final combined cost, by 100. The PPO loop uses gamma=1 and resets both TD continuation and recursive GAE at `done`; complete 48-step episodes enter each update, so no terminal bootstrap or episode-boundary leakage occurs. GAE lambda=.95 changes the advantage estimator but not the undiscounted H+tail physical outcome or reward scale. Existing physical replay independently checks 64 ticks and H/tail accounting.

The L1 collector stores the sampled action index, the categorical log probability computed at collection, the critic value, mask-containing encoding and reward. Updates recompute the same masked categorical distribution and use stored old log probability in the clipped ratio. Actor and critic parameters share the Adam optimizer and both receive nonzero gradients in crafted tests. No batch normalization, dropout or mutable observation normalization exists. The L2 diagnostic updater was tested against the frozen L1 updater under identical RNG state and produces exactly equal actor/critic parameters for S/F/A; it adds sampled telemetry only. It measures pre/post global clipping norms to determine whether clipping suppresses the actor. No outcome-dependent clip change is allowed.

The catalogue is the complete all-idle action universe and each state mask equals the exact legal subset. WAIT has fixed index zero. S and A receive identical component/worker/public features and a joint matching scorer; A removes cross-entity inputs only in the pre-scoring messages. Busy worker remaining time has a tested path into S valid logits. F receives the same flattened features and an injective edge-indicator plus matching-cardinality action code. L1 text inaccurately calls that code an action-ID one-hot vector; the code is information-complete for this catalogue, and L2 retains it unchanged. L1 conclusions are not revised on this documentation discrepancy.

PyTorch `Categorical(logits=...)` normalizes logits, and the collector's greedy decision uses `argmax(dist.logits)` with the first catalogue index resolving exact ties. An earlier L1 auditor compared raw logits at a numerical near-tie; v3 corrected the auditor without changing collector behavior. L2 records normalized-logit and probability gaps at every DEV decision and independently replays the exact chosen action. No tie rule is changed based on outcomes.

Physical failure uniforms are keyed by physical seed, tick, machine and component and are independent of action-sampling RNG. L1 DEV occurred after training, so evaluation could not alter a continuing training trajectory. L2 keeps that ordering and uses a separate Torch generator for each stochastic evaluation episode. Same physical DEV seeds are paired across arms/modes; four action seeds are nested inside each physical seed. Future physical uniforms are never actor inputs.
