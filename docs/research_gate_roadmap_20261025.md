# Research roadmap after V22

This is a conditional plan, not authorization to run every stage. One scientific diagnostic is current: [score–decoder alignment](score_decoder_alignment_diagnostic_prelock.md). V1–V22 verdicts stay closed. Numeric ceilings below are proposed planning limits for later protocols; they are **not** outcome gates or seed assignments until a separate prelock fixes them.

| Stage | Question and gate to advance | Proposed maximum new budget | Stop rule |
| --- | --- | --- | --- |
| 0. Evidence and question | Audit V13–V22 claims/artifacts; lock one uncertainty and diagnostic. | Documentation and read-only artifact checks. | Stop if provenance fails; preserve old verdicts. |
| 1. Score versus execution | Frozen C21 G/S/candidate-oracle comparison, in-bank description then fresh Bank-A/B continuation labels; exact path and independent replay gates. | 48 F1 episodes, ≤144 state/root rows, ≤18,432 forced branches, four hours collection plus four hours audit. | Apply the explicit three-way decision in the diagnostic prelock. No learner follows automatically. |
| 2. Fit, generalization, PPO retention | Only if Stage 1 or another training-only check identifies weak ranking. Prelock fixed tiny set → full training bank → separate validation states, then before/after PPO rank/action comparison. | Proposed ≤3 roots × 2 cases, ≤512 fixed tiny-set updates, ≤508 existing bank rows and ≤144 new validation rows; no full new physical campaign. | Stop at first identified failure mode; no repeated V19 rehearsal or V21 loss sweep. |
| 3. One learning intervention | Only for a localized mechanism; write proposal/prelock with fixed variables, falsifier, controls and practical threshold before code/outcomes. | One intervention and one matched pilot design; no parallel architecture search. | Stop if no mechanism predicts a measurable, attributable action/cost change. |
| 4. Physical pilot | Fresh paired H+tail simulator panel with dynamic, separately trained frozen, same-weight freeze and strong full-information/risk/rollout controls, as applicable. | Proposed ≤3 training roots × 2 cases × 32 paired physical seeds; exact training, label and forecast budgets separately prelocked. | Any failed audit, attribution, practical magnitude, case/root consistency or strong-control gate closes the pilot. |
| 5. Independent confirmation | Only after pilot eligibility: new training roots, physical seeds, predefined operating configurations and compute accounting. | Proposed same maximum panel size as Stage 4, with new seed roles; TEST remains separately permissioned. | Failed replication or deployment-cost gate closes the positive claim; no extra panel rescues pilot. |
| 6. Synthesis | Scope positive or negative conclusion to tested contracts, budgets and controls; check novelty against primary literature if a novelty claim is made. | No simulator budget. | Finish when confirmation suffices or no discriminating hypothesis remains. |

Every proposed pilot must retain the same information and physical action set across its matched comparisons; report actor/critic parameters, simulator decisions, label/forecast transitions, inference time and wall time. Full-information direct/structured/flat, risk matching, rollout and always-request controls must be either matched or explicitly identified as external references under a versioned protocol. Keep failed and partial timestamped artifacts. No old held-out or TEST outcome chooses a new design.
