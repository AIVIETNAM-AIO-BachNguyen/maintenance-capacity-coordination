## Distinct learnability hypothesis

The v8–v12 PPO actions were **ordered** internal edge/STOP paths. A physical matching of cardinality r may have r! valid edge orders, each with the same physical H+tail reward. Exact path PPO was correct, yet this multiplicity may dilute credit for economically different second assignments even when the v13 independent-tape signal shows such differences. V14 uses the minimal canonical path: edge indices must increase strictly after each chosen edge; STOP is available whenever a legal next edge exists, and no edge means forced end. Every legal physical matching, including WAIT and nonmaximum-cardinality matchings, has **exactly one** sorted-edge path. The actor still recomputes present-state residual matching context after each provisional assignment, and the simulator executes only the completed matching once.

For C14/D14/B14, candidate-conditioned residual summaries from v12 are recomputed using the **canonical feasible successor graph**: after proposed edge e, only higher-index, nonconflicting, currently admitted/compatible/idle edges remain. C14 refreshes these summaries and selected-edge context after each provisional edge. D14 has the **same modules, initial logits, raw information and legal physical matching set**, but freezes all root candidate/STOP contexts within the tick while feasibility still updates. CF14 loads each DEV-selected C14 checkpoint into D14 only at inference. B14 uses direct entity features with the same canonical sequence/graph mechanism. U14 uses the same encoder/scorer widths and raw information as C14 with the earlier unrestricted ordered-edge paths and corresponding residual graph; it is a scratch **sequence-multiplicity control**, not a frozen historical C12 checkpoint. S14 structured complete-action, G14 flat full-information complete-action and Q14 flat always-request complete-action PPO are scratch controls. F1 risk matching and F2 six-tick rollout are same-panel rule/forecast references. Historical frozen N4/K2 V14 (the old model with that name) cannot score N5/K3 and remains an external reference only; the experiment arm names C14/D14 etc are version labels, not that historical checkpoint.

This proposal inherits recursive matching, STOP and shared entity encoders from prior art such as AirME/HetGPO; sorted-path canonicalization is a formulation choice, not a novelty claim by itself. The candidate residual context may help rank remaining assignments, but no gain is assumed. C14−D14 and C14−CF14 test **feedback**; C14−U14 tests whether canonicalizing the physical matching path helps learning; C14−B14 tests the shared demand/capacity embedding; C14−S14/G14 tests against complete-action structured/flat alternatives. Gains against G14 alone do not validate feedback. The same-weight CF14 physical rollout, not action-change counts, is decisive for deployed update usefulness.

## Operating contract and probability

Keep the two fixed `n5k3_residual_a/b` configurations from `family_config("n5_k3_sparse", 74740000/74740001, "full")`, with horizon 64 only for H48+tail16. This intentionally tests learning in the **same qualified economic regime** as v13 but on entirely fresh physical tapes and scratch roots; neither case can be dropped based on outcomes. Preserve threshold PM, automatic CM, non-preemptive service, failure/restoration/cost law, no future-event input, no reservation, fees or forced shutdowns. Q14 alone uses always-request admission and is not an architecture attribution control. All same-admission scratch arms have the same 136-action physical matching/WAIT catalogue and present-state information; internal probability factorization differs.

Canonical C/D/B14 use PPO on unique increasing-edge token paths. Exact masked conditional log probabilities sum to the **physical matching log probability** because the mapping from path to matching is one-to-one. Per-sampled-path conditional entropy sum is reported as a path statistic, not mislabeled the full policy matching entropy. U14 still has order multiplicity and its PPO log probability remains that of the sampled path, not the matching marginal. All sequential actors assign one physical reward to the completed path and use exact old/new log probability for PPO ratios. S/G/Q14 use one masked categorical over complete matchings. STOP at root means WAIT, after an edge yields a partial matching, and exhausted successors force termination. Deterministic evaluation is tokenwise greedy; it need not maximize matching probability. No internal decoder step advances time, consumes a failure event, charges cost or physically occupies a technician.
