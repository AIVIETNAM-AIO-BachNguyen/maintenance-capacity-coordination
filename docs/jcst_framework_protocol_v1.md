# JCST/1.1 first demand–capacity learner campaign — protocol L1

Status: Stage 0 pre-outcome lock candidate, 2026-10-26 Asia/Taipei. This protocol becomes frozen when the engineering checks and runtime estimate are recorded below, before any TRAIN/DEV learner outcome is inspected. C1 is closed background evidence; its existing files and seed banks are not modified. No sealed TEST is opened. The direct user goal authorizes local Linux scientific execution after the checks, without branch, commit, push, SSH, rsync or remote work.

## Scientific question and contract

Can a structured, centralized demand–capacity representation (S) learn lower undiscounted H+tail cost than a full-information flat actor (F) and an equal-information interaction ablation (A), and remain economically competitive with C1 threshold5? Both **base** and **generalist** are required, reported separately. JCST/1.1 physics, information, all legal complete matchings, WAIT, H=48, fixed risk tail B=16, all-healthy/age-zero/free initial state, costs, deterministic durations and failure law remain exactly as C1. The policy sees current state and public parameters, never actual future noise. No requester is introduced; these are single-actor centralized policies, not two-policy MARL. Learned embeddings are features, not calibrated economic value.

Primary estimands, in simulator cost units (negative favors S): mean physical episode cost differences S−F, S−A and S−threshold5, per case, crossing independent training-seed and physical-seed variation. The effect of architecture includes the whole actor/training path at a fixed information, action and sample budget; it is not a causal estimate of a particular embedding coordinate. Reference controls are threshold5, fixed risk/duration matching, corrective-only, bounded R2 rollout and WAIT. R2 uses public model forecasts and is separately marked for model access and forecast compute. Historical requester/always-request policies have no corresponding JCST requester role and are inapplicable.

## Representations and learning

The raw information is component operating age, failure, deterministic public hazard, Weibull scale/shape, derived machine service/breakdown mode and per-technician durations; technician free/busy, remaining time, target machine/component, PM/CM kind and public duration/compatibility vector; normalized current tick, H/B and four cost coefficients. All three actors get exactly these features. The global critic is the same two-layer 64-unit tanh MLP on the flat full state in every arm. A complete-matching action universe is the legal catalogue for the all-idle state; each observed legal catalogue is its exact subset mask. Every healthy component is PM-eligible at all ages, every failed target is CM, simultaneous starts and WAIT remain legal.

S encodes each component and worker, passes bidirectional component–worker duration-conditioned messages across all pairs (including busy workers), then scores whole candidate matchings from selected pair embeddings plus global component/worker pools and public features. Its final MLP jointly sees up to K selected edges; the score need not be additive. A has the same modules and parameter count, but its component message gets zero worker embedding and its worker message gets zero component embedding; each still receives own state and public durations, and the final matching MLP still combines both sides. This removes only the pre-scoring cross-entity message mechanism. F uses the exact flat state and a full one-hot complete-action representation in a direct MLP. F width 70 was chosen before outcomes for actor parameter difference below 10%; exact counts are logged. Actor input access and critic are otherwise matched.

One standard masked PPO implementation is shared. Adam learning rate 3e−4, four epochs, minibatch 128, clip 0.2, entropy coefficient 0.01, gradient norm cap 0.5, GAE lambda 0.95, gamma **1.0**, reward = negative (controlled step cost + tail cost on final controlled step) divided by 100. Complete 48-decision episodes are collected; no terminal bootstrap, no time-limit truncation bootstrap, no other reward or auxiliary loss. Returns are therefore undiscounted H+tail cost on a linear scale, although GAE lambda changes advantage estimation. Each arm has identical training interactions, update schedule and checkpoint selection. Torch and simulator run one CPU worker/thread; no GPU.

## Fixed banks, budgets and stage rules

All raw physical seeds are below 2^64 and derive from base 2^42 plus disjoint role offset (engineering 0, engineering evaluation 600,000,000, TRAIN 100,000,000, DEV 200,000,000, CONFIRMATION 300,000,000, replication TRAIN 400,000,000, replication evaluation 500,000,000), case index × 10,000,000, independent training-root index × 100,000 and episode index. There are no overlaps with C1's 10–14 million bands or the historical ~tens-of-millions banks. Actual future noise is used only in transition. Same raw physical seed is paired across arms and roots during evaluation, and across controls. Torch initialization/minibatch seed is separately derived from the root bank and case; roots 0–4 are independent training replicates in each arm/case. Engineering seeds are excluded from science.

The campaign permits **one fixed S/F/A design round** and reserves no outcome-guided tuning in this L1 protocol; the allowance of up to three rounds is a ceiling, not a requirement. TRAIN: 24,000 H-decision simulator samples (500 complete episodes) per root × five independent roots × three arms × two cases = 720,000 H decisions, with PPO updates every 25 episodes. Save 6,000, 12,000 and 24,000-sample checkpoints and common-sample learning curves. DEV: 16 fresh physical episodes per root/checkpoint/arm/case, plus the controls on the same 16 raw seeds. Select one checkpoint **per case and arm** by lowest mean DEV H+tail cost averaged equally over its five training roots and 16 physical seeds, tie to earlier sample count. Keep all five roots at that checkpoint. No winner is selected between S/F/A; all continue to confirmation if TRAIN/DEV source, replay and selection audit pass. A failed or incomplete panel is invalid, not a negative scientific result.

After locking source hashes, selected checkpoint counts, analysis code and all hypotheses, confirmation evaluates the selected five root checkpoints per learned arm on 128 fresh paired physical seeds per case, and evaluates all five controls once on those physical seeds. No model or checkpoint selection is made using confirmation. Replication is eligible only if both cases meet all predeclared confirmation conditions below and independent audit passes. It trains five **new** roots per learned arm/case from scratch with the same 24,000 samples and the already frozen checkpoint counts, then evaluates 128 fresh paired physical seeds per case. Replication does not choose new hyperparameters or use confirmation seeds.

Maximum scientific elapsed wall time is 72 h: TRAIN/DEV 48 h, confirmation 12 h, replication 12 h. No time or sample extension is allowed after outcomes, even near a gate. One CPU worker, one Torch thread, no GPU, maximum 8 GiB process RAM and 30 GiB per stage directory; do not contend with existing workloads. Preserve any failed/partial artifact. If engineering runtime indicates these fixed budgets cannot fit, reduce the design and revise this pre-outcome protocol before launch, or report the blocker.

## Outcomes, uncertainty and decisions

Primary physical outcome is undiscounted H+tail total cost. Report H, tail and preventive/corrective/unavailable/failure charges separately, plus PM/CM starts, failure, downtime, technician occupancy, WAIT and endpoint backlog. Also report per-root cost, equal-sample learning curves, training and inference time, peak memory, control forecast transitions and model access. No equal-sample result is described as matched wall time. All physical evaluation seeds are paired. Training roots and physical seeds are two independent sources of variation; ticks, minibatches and forecasts are not independent replicates.

For each case/contrast, estimate the equal-root/equal-physical mean difference. Use a two-way crossed nonparametric bootstrap with 2,000 pre-seeded resamples: resample physical seed indices jointly across arms and controls; independently resample training roots within each learned arm; threshold's single physical result is *not* multiplied into 5 independent observations. Compute percentile 99.17% two-sided intervals (Bonferroni family of six case × contrast primary intervals). Fixed bootstrap seed = 2^42+900,000,000. No adaptive precision extension. The root resample is independent across actors despite matched physical seeds, avoiding artificial actor-root pairing; raw per-root means are also shown. Equal case weighting is used for descriptive pooled summaries only; no pooled win can hide a failed case.

Representation support requires S−F mean ≤−10 and multiplicity-adjusted upper interval <0 in **both** cases. Mechanism support requires S−A mean ≤−10 and adjusted upper <0 in both. Economic competitiveness requires S−threshold5 mean ≤+10 and adjusted upper ≤+10 in both; this is a noninferiority margin of roughly 1.2–1.3% of C1 threshold cost, not a monetary claim. The −10 practical gain is roughly 1.2–1.3% of those C1 means; these thresholds were chosen from C1 scale before L1 learner outcomes. The full first-framework objective requires all three conditions in confirmation **and** the same three conditions on fresh independent training replication, with each case evaluated separately. If only one component passes, report only that component. A gain versus risk or R2 cannot substitute for threshold5 competitiveness. If confirmation fails, close L1 without replication. If replication fails, report nonreplication. No efficiency-success claim replaces a cost failure; compute remains descriptive.

## Validation, run management and audit

Before scientific outcomes: focused tests, full regression, bounded local Linux train/eval smoke, checkpoint save/load and independent physical replay. Tests cover complete catalogue/mask, early PM/CM, simultaneous starts and WAIT, H/tail accounting, gamma=1 and terminal reward, log-probability/action-index mapping, actor and critic gradients, busy-worker remaining-time and cross-message paths, deterministic evaluation, no future-noise input, seed separation, normalization and checkpoint round trips. Engineering crafted states verify paths and legality only, not prevalence or economic value. Record runtime and memory from smoke below before scientific launch.

Every stage makes a new UTC timestamped directory with refusal to overwrite, protocol/source/config/checkpoint hashes, Git status, machine and package versions, exact command, budgets, role-separated seeds, progress, raw complete and partial episode rows, checkpoints and terminal status COMPLETE/INCOMPLETE/INVALID. Resume is not supported in L1; an interrupted panel remains incomplete and must be restarted under a fresh directory with identical source, configuration and seed roles. No two source revisions may be pooled. Logs contain action-index/action, each H and tail cost component, counters and final state; independent audit reconstructs the full catalogue and each physical transition from seed, checks all H/tail arithmetic and checkpoint/selection provenance, and independently recomputes contrasts/bootstrap/gates. A self-check is labeled as such. A scientific bug stops affected stages; retain bad artifacts, fix to contract, rerun checks and the entire affected panel under one source hash.

No sealed TEST, branch, commit/push, SSH, rsync or other-machine run is authorized. C1 and v1–v22 artifacts remain untouched. This file and CURRENT_STATE.md describe the only current learner campaign.
