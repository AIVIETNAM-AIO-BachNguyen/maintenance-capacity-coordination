# Structured demand–commitment pilot v3 — prelocked protocol

Status: LOCKED BEFORE V3 LEARNING OUTCOMES, 2026-10-22 (Asia/Taipei). This is one new pilot following the failed v2 early-PM headroom gate; no v1 TEST outcome or v2 diagnostic seed chooses its architecture, action set or hyperparameters. It uses the unchanged simulator and inherited threshold-request contract. The two pilot cases are N4/K2 `reciprocal_scale2` and `specialist_generalist_scale2`, H=48 plus the common 16-tick threshold/risk-matching tail.

## Question and hypotheses

At equal information/action set and finite PPO training budget, does shared machine-demand and worker-commitment factorization improve H+tail economic cost or learning speed against a direct-health centralized actor? H1: the operational matching problem has interactions, but this pilot does not assume a guaranteed gain over strong rollout; same-panel F2 quantifies remaining cost gap, and F2 is not an optimum. H2: structured S improves cost over direct-health G3 under matched conditions. H3: remaining busy-time context matters; S should outperform same-architecture R, which masks only numerical remaining-commitment features. A failed H2 means no claimed structural learning benefit; a failed H3 means no attributed remaining-time benefit.

## Contract, action set and actors

At each H tick, submit the inherited fixed-threshold PM requests, then observe the admitted full present state and choose one legal partial machine–technician matching or WAIT. This is exactly G's request/matching contract. Queued PM persists, failed machines automatically receive CM/upgrade, and service is non-preemptive. No machine output masks, adds or removes actions; none is a separate requester. The same deterministic 16-tick tail applies to all learned arms. Physics, hazard, restoration, skills and economic reward `-cost` are unchanged. Future physical event tapes are never model inputs. A full-current-information critic sees the present predecision state.

| Arm | Actor and current information | Action set |
| --- | --- | --- |
| S | Shared per-machine encoder, shared worker encoder, edge/action fusion | Fixed-threshold legal matching/WAIT |
| R | Exactly S with numerical worker/machine remaining-time inputs zeroed in actor only | Same as S |
| G3 | Flat direct-health full-information MLP receiving the same raw per-machine/worker inputs as S | Same as S |
| D3 | Flat full-information learned coordinator after always-request PM admission | Broader request history; contextual, not H2/H3 attribution |
| A/F1/F2 | Frozen V14 count, risk matching, six-tick/16-scenario rollout | Inherited fixed-threshold action set; descriptive strong controls |

Machine inputs contain present local physical/request state, case constants and skill/duration/restoration edges. Worker inputs contain free/busy, remaining time and current assignment. R zeros only numerical remaining-time fields while retaining free/busy, skills and the matching mask. S/R have identical architecture and parameter count. G3 uses a flat concatenation of the same S raw inputs, not an information-restricted strawman. Tune G3 hidden width **only before outcomes** to within 10% of S actor parameter count; critic architecture is identical. Report exact actor/critic counts. All learned arms use standard categorical PPO log-probability for the one sampled matching, not the v1 two-stage joint likelihood.

## Metrics, estimator and gates

Primary: paired selected-policy H+tail economic cost, S minus G3 and S minus R, by case and training seed, equal weights. The 32 held-out physical seed IDs are shared by every arm and case. For conditional physical uncertainty, resample the **raw physical seed ID as one cluster across all arms, training seeds and cases** (5,000 draws, analysis seed 73187000); do not treat repeated episodes on a tape as independent. Report per-training-seed differences separately and distinguish this conditional interval from training-seed variability. Secondary: H availability/failures, PM/CM waiting, backlog at H and end, service starts, legal-service WAIT, DEV cost curves/area over 2,048–8,192 decisions, forecast transitions, model size, total H and tail transitions, policy inference and wall time. Compare learning area separately from selected-policy cost and F2 deployment speed separately from its planning forecast budget.

The pilot-to-independent-training-replication gate passes only if S−G3 has an overall H+tail mean at most −30.0, both case means below zero, at least two of three paired training-seed means below zero, and the 95% clustered physical-seed interval upper endpoint below zero. The −30 threshold is a predeclared practical gain of about 3% near the pilot's ~1000-cost scale. H3 has no gate: S−R is reported regardless. A/F/D3 are reported honestly but cannot replace G3 in H2. If gate fails, do not open independent training replication or TEST. If gate passes, retrain all four learned arms on the fresh replication training seeds with the identical protocol, then apply the same analysis to their new physical panel. A new TEST may be proposed only after audited independent-training replication supports the same H2 direction and the user separately authorizes it. No gate is lowered after results.
